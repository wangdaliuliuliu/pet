# Pet setup

用户刚拉下项目或首次请求启动时，立即进入配置引导，不等用户主动问缺什么。先运行 `npm run doctor -- --json`（只读，不访问 AI）。读取 [配置说明](references/configuration.md)。配置已存在也只报告字段是否具备，不能打印值。

## 必须主动完成的对话

先简短说明：“本机基础版无需填写 key；公网访问需要自己的访问密码。聊天、转文字、发声、看图、继续 AI 进化和旅行都是选配，不填仍可玩基础版。”

然后主动问两项，可合并为一次提问：

1. 本机试玩，还是用用户自己的托管账号上线？默认推荐本机先跑通。
2. 先只玩基础版，还是启用哪些选配？明确允许全部跳过。昵称仅选填，默认叫“朋友”，不要索取真实姓名或年龄。

用户选择本机：使用默认存档位置和端口；硬性条件只剩 Node.js 22+、可写目录、端口可用，智能体负责准备与验证。不要为不存在的“必填 API key”阻塞基础运行。

用户选择联网：`PET_ACCESS_PASSWORD` 至少12字符，是硬性必填；`HOST=0.0.0.0`。账号登录和平台授权确实需要本人时才请求。密码、key 通过安全本地输入或平台 secret 填写，绝不展示或提交。

用户选择某个选配：按说明只问该功能所需的 key、提供商地址和模型/声音。解释缺失会让该功能不能用，而不影响基础版；若用户不想填，恢复禁用而不反复追问。只填 key 不代表服务通、模型支持或免费，实测收费需用户授权。

## 执行

可用 `npm run setup` 的交互向导安全地填写本地配置，也可以由智能体根据用户答案生成 `.env`。向导不访问供应商；选配 key 在终端隐藏。不要覆盖现有配置或私人进度而不告知。查看 [配置说明](references/configuration.md) 后安装所选功能需要的依赖。

运行 `npm run doctor`，硬性条件满足后 `npm start`；基础版用全新空数据，测试不用任何原用户资料。基础两次进化使用仓库预制美术与完整动作，不需要生成 key。`PET_ENABLE_GENERATION=0` 与 `PET_ENABLE_TRIPS=0` 默认关闭额外收费调用。

要上线时读取 [部署说明](references/deployment.md)，只用用户自己的账号。准备模板、检查和操作由智能体完成，不退回项目开发者的原服务器。临时免费试玩与长期保档必须讲清楚；不要自动付费升级。没有登录权限时只请求必要授权，继续完成不依赖授权的准备。

要换角色时读取 [角色替换](references/customization.md)。美术、动作清单和提示词须保持一致。

交付分别报告：必填条件满足、选配已填未实测、基础浏览器验证、实际供应商验证、云端部署及重启保档。未测的项目不能写通过。自动发现技能的依据见 [官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)；如果宿主不自动发现，让它读取根目录 `AGENTS.md` 和此入口，而不是承诺所有智能体必定自动运行。
