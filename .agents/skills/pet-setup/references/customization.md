# 选配角色替换

默认小猫有三套完整形态：`public/assets/pet/stage-0.png`、`stage-1.png`、`stage-2.png`。后两套各有匹配的9个部件与动作清单，放在 `public/assets/pet/animations/stage-1/` 与 `stage-2/`。不用复制任何玩家存档。

`pet-art.json` 是素材索引，当前运行时代码直接使用上述路径。原图仍是原有白底 RGB；两次进化是透明 RGBA。默认门槛为3、8次喂食。只有显式启用图片生成后，后续15、25次门槛会生成新图与新动作，并在完整绑定前禁止继续进化。

替换时只问选填的角色称呼/外观、用户有权使用的原图、预制成长图和可用动作；不要询问真实家庭故事。换一张图不等于完整替换：`evolution-service.js` 的身份锚定、`animation-service.js` 的图集要求、`voice-service.js` 的聊天/旅行角色描述、`public/` 的标签都要对应调整。

动作是 `front-cat-v1` 骨骼；换物种不能强行复用猫的部件。缺少匹配部件时标记未完成，不能沿用旧翅膀。清单 `formImage` 必须绑定新图。保持公共显示比例和脚部锚点，核对待机、眨眼、跳舞及结束回到待机。

完成后跑测试与 `npm run check:evolution`，再做浏览器视觉验证；新图片生成需要单独授权费用。所有示例使用虚构资料或合成测试音频。
