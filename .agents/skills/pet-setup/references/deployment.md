# 在用户自己的环境上线

先确定用户要临时免费试玩，还是保留长期进度。代码是 Node HTTP 服务，不能只上传 `public/` 到静态网站。使用仓库 `Dockerfile`，内置 Node、Python、FFmpeg 和可选图片工具依赖。不要上传 `.env` 或 `data/`。

## 临时免费试玩

仓库提供 `render.yaml`：Render Free Docker web service，平台 HTTPS，访问密码由平台生成；确认免费计划再创建，绑定用户自己的 GitHub 仓库。不需要开发者的任何服务器权限。

按 [Render 官方限制](https://render.com/docs/free)（2026-10-14 核查），免费实例会休眠且本地写入在重启、重新部署或休眠后消失，不能挂持久磁盘。因此此模板只能叫**临时试玩**。`PET_DATA_DIR=/tmp/pet-data`。不可在演示中声称会长期保留孩子的照片、记忆或进度。用户不接受丢档就不要部署这条路线。

智能体先做文件/构建/配置检查，然后在用户自己的 Render 账号创建或引导 Blueprint 导入，实例选 Free。托管登录/账号验证/仓库授权由用户本人完成；其他工作尽量自动完成。`PET_ACCESS_PASSWORD` 在 Render 环境变量里查看和使用，不能打印到对话。其余 AI key 由用户自己按需填入 secret；默认生成和旅行关闭。不要绕过平台休眠政策或自动升级套餐。

## 长期保档

目前仍为 JSON + 本地文件存储，没有 SQL 或远程存储适配。用用户自己的、有持久盘的服务器/托管环境，将 `PET_DATA_DIR` 设到持久目录；这类环境可能收费，不能替用户选择付费计划。Docker 的 `/app/data` 可以挂自己的 volume。免费持久托管是否可获得需按用户账号和当地服务核实，不能承诺永久免费。

必填：绑定非回环地址时自己的访问密码至少12字符。公网通过 HTTPS 反向代理/平台 TLS；HTTP Basic 密码认证应只经 HTTPS 使用。所有实例内的数据共享一份，密码是实例级保护，不是多人账号体系。多个家庭要分别部署，不把一份实例当多租户产品。

验证：`/healthz` 公共只返回健康状态；其他页面、历史、媒体及 API 均需密码。检查正确/错误密码、HTTPS、缺 key 提示、数据目录，以及目标存储在服务重启/重新部署后能否恢复。真实手机麦克风权限单独实测，不能用健康接口 200 代替。
